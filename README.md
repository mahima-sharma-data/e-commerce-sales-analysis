# e-commerce-sales-analysis using SQL
## Project Overview
This project focuses on analyzing e-commerce sales data to uncover hidden trends, customer behavior, and key business insights using SQL.

## Key Insights Addressed
- Top-performing product categories and items.
- Monthly and quarterly sales growth trends.
- Customer segmentation based on purchase frequency and total spend.
- Identification of high-value regions and peak shopping hours.

## Tech Stack Used
- Database: MySQL
- Tools: SQL Queries, Data Extraction & Analytics
